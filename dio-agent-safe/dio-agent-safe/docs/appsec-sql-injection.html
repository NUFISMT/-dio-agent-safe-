Quando texto vira SQL

Uma consulta SQL montada por concatenação de texto trata o que a pessoa digitou como parte do comando, não como um dado isolado. É assim que nasce a SQL Injection (CWE-89).

Interpolação insegura × consulta parametrizada

⚠️ Interpolação direta

query = (
  "SELECT * FROM usuarios "
  f"WHERE username = '{usuario}' "
  f"AND password = '{senha}'"
)
cursor.execute(query)

✅ Consulta parametrizada

cursor.execute(
  "SELECT * FROM usuarios "
  "WHERE username = ?",
  (usuario,)
)
# + hash de senha com salt
# para comparar, nunca texto puro
